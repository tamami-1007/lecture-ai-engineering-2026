## 宿題

- 取り組んだレベル：基礎

- 変えた設定やデータ：
  - `lora_r`を変更した。
  - 元の設定：`lora_r = 16`
  - 変更後の設定：`lora_r = 8`
  - `lr`は`0.0002`、`num_train_epochs`は`20`のまま変更しなかった。
  - 設定変更後、ランタイムのセッションを再起動し、ノートブックを上から実行した。
  - 元の設定と変更後の設定で、自分で学習を実行した。
  - 元の設定の結果ファイルは`result_baseline_rerun.json`、変更後の結果ファイルは`result.json`として保存し、比較した。

- 結果（比較表や数字）：

  | 項目 | 元の設定 | 変更後 |
  |---|---:|---:|
  | `lora_r` | 16 | 8 |
  | `lr` | 0.0002 | 0.0002 |
  | `num_train_epochs` | 20 | 20 |
  | `format_rate` | 1.0 | 1.0 |
  | `content_rate` | 0.9047619048 | 0.8571428571 |
  | 最終 loss | 0.013796 | 0.013395 |
  | 学習時間 | 244秒 | 243秒 |

  元の設定では、学習前は`format_rate = 0.0952380952`、`content_rate = 0.0`だった。学習後は、`format_rate = 1.0`、`content_rate = 0.9047619048`になった。

  変更後の設定では、学習前は`format_rate = 0.0952380952`、`content_rate = 0.0`だった。学習後は、`format_rate = 1.0`、`content_rate = 0.8571428571`になった。

  どちらの設定でも`format_rate`は1.0になった。`content_rate`は、元の設定のほうが変更後より高かった。最終 lossは、変更後のほうが少し低かった。学習時間は、元の設定が244秒、変更後が243秒で、今回の実行ではほぼ同じだった。

  `result.json`の`seconds`は評価時間であり、表の「学習時間」には学習セルに表示された学習時間を記録した。元の設定の最終 lossは`trainer_state.json`の最後の学習記録で確認し、変更後の最終 lossは学習セルの最後の`Training Loss`で確認した。

- ファインチューニングが向く場面・向かない場面についての考察：
  - 今回の実験では、ファインチューニングによって、どちらの設定でも`format_rate`が学習前の約0.095から1.0に上がった。このため、回答の形式を一定にしたい場合や、決められた形式で回答する例を学習させたい場合には、ファインチューニングが向くと考えた。
  - 一方、今回の実験では、`lora_r`を16から8に変更すると、`content_rate`は0.9047619048から0.8571428571に下がった。設定によって結果が変わるため、少ないデータで学習する場合は、設定を変えて評価する必要がある。
  - ファインチューニングは、回答形式や特定の作業手順など、学習データに例があるパターンを身につけさせたい場面に向くと考えた。
  - 最新情報や学習データに含まれていない情報を正確に答えさせたい場面では、ファインチューニングだけに頼るのは向かないと考えた。今回の実験でも、学習前後の数値を比較して効果を確認する必要があった。
  - したがって、ファインチューニングは「回答の型を覚えさせる」用途には向くが、常に最新の知識を参照する用途では、検索などの仕組みと組み合わせる必要があると考えた。
